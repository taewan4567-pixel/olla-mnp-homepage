# 올라 M&P 솔루션 홈페이지

외국인 환자 유치업 회사 **올라 M&P 솔루션**의 공식 홈페이지 소스입니다.

## 구조

```
index.html      # 단일 페이지 (회사소개 / 서비스 / 진료분야 / 이용절차 / 차별점 / 문의)
css/style.css   # 스타일 (반응형, 모바일 대응)
js/main.js      # 모바일 메뉴, 문의 폼 처리
assets/         # 로고, 사진 등 이미지 (추가 예정)
```

프레임워크나 빌드 도구가 없는 정적 사이트라서 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 배포

- **GitHub Pages**: 저장소 Settings → Pages → Branch `main`, folder `/ (root)` 선택
- **Netlify / Vercel**: 저장소 연결 후 빌드 명령 없이 배포 디렉터리를 루트로 지정

## 채워야 할 내용 (플레이스홀더)

- 이메일 주소 (사업자·유치업 등록번호, 주소, 전화는 반영 완료)
- 히어로 영역 실적 숫자 (제휴 병원 수, 유치 국가 수 등)
- 로고 및 대표 이미지 (`assets/`)
- 개인정보처리방침 / 이용약관 페이지
- 문의 폼 백엔드 (현재는 mailto 방식) → Formspree, Google Apps Script 등으로 교체
- 다국어 페이지 (EN / 中文 / RU) — 헤더 언어 버튼은 자리만 잡아둔 상태
